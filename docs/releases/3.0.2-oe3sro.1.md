# WSJT-X OE3SRO Custom — erstes Windows-Release

**Paketversion: 3.0.2-oe3sro.1 · Windows x64 · build by OE3SRO**

## Download und Start

- **`wsjtx-OE3SRO-3.0.2-oe3sro.1-windows-x64.zip`**: vollständige Anwendung
  mit EXE, Decodern, Hamlib-Tools, Qt/OpenSSL-DLLs, Stationsdaten und Dokumentation.
  Das ZIP vollständig entpacken und **Start-WSJT-X.bat** doppelklicken.
- **`wsjtx-OE3SRO-3.0.2-oe3sro.1-documentation.zip`**: deutsche und englische
  Anleitung separat. Entpacken und **docs/index.html** im Browser öffnen.
- Die Anleitung **docs/index.html** liegt auch im Windows-Paket. Beim ersten
  Start Rufzeichen, Locator, Funkgerät und Audio unter **Settings** einrichten.
- Vorhandene Custom-Einstellungen bleiben erhalten. Persönliche INI-/Logbuchdaten
  sind nicht im Download enthalten. SHA256-Dateien liegen neben beiden ZIPs.

## Enthaltene Erweiterungen

Integrierte **PSK Reporter — Who hears me?**-Liste für Rufzeichen, Band und Modus
des laufenden Hauptfensters; Band-/Frequenzansicht, Aktualisierungs-Countdown,
WSJT-X-Logbuchfarben, Suche und Favoriten. **Call station**, **Repeat last**,
**Call next**, Anrufhistorie und **Halt Tx** unterstützen die Stationsauswahl.
**Call station** aktiviert TX für den nächsten eingestellten TX-Zeitraum.

FT2 ist unter **Mode → FT2** verfügbar und bleibt experimentell. Die Implementierung
adaptiert WSJT-X Improved von **DG2YCB**, heute WS Suite. Basis ist **WSJT-X
3.0.2-devel**; dies ist eine Custom-Veröffentlichung des OE3SRO-Forks.

## Prüfungen und Quellcode

Der Release-Build wird in GitHub Actions gebaut und erst nach erfolgreichen
PSK-Reporter-, FT2-/FT4- und Paketlaufzeitprüfungen veröffentlicht.
`build-info.json` dokumentiert den genauen Quellcommit und den EXE-Hash.
Quellcode und GPLv3-Lizenz stehen im Release-Tag und im Download bereit.

## English

**First Windows x64 release — package version 3.0.2-oe3sro.1 · build by OE3SRO.**

Download the **windows-x64.zip**, extract it completely, and double-click
**Start-WSJT-X.bat**. The EXE, decoders, Hamlib tools, Qt/OpenSSL DLLs, station data,
and documentation are included. Open **docs/index.html** for the German/English
guide; the same documentation is also available as a separate **documentation.zip**.
Configure your callsign, locator, radio, and audio in **Settings** on first launch.
Existing Custom settings are preserved. No personal configuration or logs are bundled.
SHA256 files accompany both ZIPs.

Includes the integrated PSK Reporter receiver list using the running program's
callsign/band/mode, refresh countdown, logbook colors, filters, favorites, calling
tools, history, and Halt Tx. **Call station enables transmission in the next
configured TX period.** FT2 is experimental and adapts DG2YCB / WSJT-X Improved
(now WS Suite). This custom release is based on WSJT-X 3.0.2-devel.

GitHub Actions builds and verifies PSK Reporter, FT2/FT4, and the standalone package
before publication. `build-info.json` identifies the exact source commit and EXE
hash. Source code is available through the release tag under GPLv3.
