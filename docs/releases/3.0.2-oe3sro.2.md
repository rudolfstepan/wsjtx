# WSJT-X OE3SRO Custom — Windows-Release 3.0.2-oe3sro.2

**Windows x64 · build by OE3SRO · Basis WSJT-X 3.0.2-devel**

## Download und Start

- **`wsjtx-OE3SRO-3.0.2-oe3sro.2-windows-x64.zip`** enthält die Anwendung,
  Decoder, Hamlib-Tools, Qt/OpenSSL-DLLs, Stationsdaten und die deutsche und
  englische Anleitung. Vollständig entpacken und **Start-WSJT-X.bat** starten.
- **`wsjtx-OE3SRO-3.0.2-oe3sro.2-documentation.zip`** enthält die Anleitung
  separat; Einstieg ist **docs/index.html**.
- Zu beiden ZIPs gehört eine **SHA256-Datei**. `build-info.json` nennt den
  genauen Quellcommit und die Prüfsumme der EXE.

Bestehende Einstellungen des Profils **WSJT-X - Custom** werden weiterverwendet.
Beim ersten Start Rufzeichen, Locator, Funkgerät und Audio in **Settings**
einrichten. Persönliche Konfigurationen und Logbücher sind nicht enthalten.

## Neu gegenüber 3.0.2-oe3sro.1

- **FT8, FT4 und FT2:** native C++-Wellenformerzeugung und gemeinsamer
  LDPC-Encoder; FT8 verwendet zusätzlich native Standard-/SMP-BP-Kerne.
  Weitere Decoderteile bleiben Fortran. Die FT4-/FT2-Synchronisationssuche
  nutzt bei ausreichend großen Suchrastern mehrere CPU-Kerne.
- **SMP:** CPU- und OpenMP-Teamlimits werden berücksichtigt; damit werden
  Hänger bei kleineren oder abgeschalteten Teams vermieden.
- **TX-Audio:** eigene Wellenformpuffer für FT8/FT4/FT2, korrigierte Behandlung
  des Nachrichtenendes und ungültiger Audioformate.
- **View → TX quality — FT8 / FT4 / FT2:** Anzeige von Audiofrequenz,
  Dämpfung, Stream-/Pufferzustand und optionalen CAT-ALC-Werten. Die
  FT8-Parallelitätsregler sind nur im FT8-Modus aktiv.
- **Logbuch:** vollständige QSOs am ADIF-Dateiende werden zuverlässig
  eingelesen, auch bei einzeiligen Dateien und mehreren letzten Records.
- **UDP:** Befehle müssen zur eigenen Instanz-ID passen; veraltete
  DNS-Antworten überschreiben keinen inzwischen geänderten Server.

Die PSK-Reporter-Empfängerliste mit Filtern, Favoriten, Anrufhistorie und
Anrufhilfen bleibt enthalten. **Call station** aktiviert die Aussendung im
nächsten eingestellten TX-Zeitraum. **FT2 bleibt experimentell** und basiert
auf der Anpassung von DG2YCB / WSJT-X Improved, heute WS Suite.

## Build und Prüfungen

GitHub Actions baut dieses Release aus dem Tag **oe3sro-v3.0.2-2** und prüft
PSK Reporter, Logbuch/UDP, die nativen FT8-/FT4-/FT2-Kerne, TX-Audio,
Codec-/SMP-Regressionsfälle und die eigenständige Paketlaufzeit vor der
Veröffentlichung. Die Prüfungen belegen keinen allgemeinen Gewinn bei
RF-Empfindlichkeit oder Reichweite.

Quellcode: Release-Tag und **Source code (zip/tar.gz)** auf der Release-Seite.
**COPYING** mit der GPLv3-Lizenz liegt beiden Paketen bei.

## English

**Windows x64 · package version 3.0.2-oe3sro.2 · build by OE3SRO.**

Download **windows-x64.zip**, extract it completely, and start
**Start-WSJT-X.bat**. The application, decoders, runtime DLLs, station data,
and German/English guide are included. Open **docs/index.html**; the guide is
also available in **documentation.zip**. Both ZIPs have SHA256 files.
`build-info.json` identifies the exact source commit and EXE hash.
Existing Custom settings are preserved; personal configuration and logs are
not bundled.

Since release 1, this version adds native C++ waveform generation for
FT8/FT4/FT2, a shared LDPC encoder, native FT8 BP kernels, and parallel
FT4/FT2 synchronization searches. Other decoder components remain Fortran.
It fixes OpenMP team-limit hangs, transmit-audio buffer and end-of-message
handling, incomplete ADIF loading at end of file, UDP instance targeting,
and stale DNS responses. **View → TX quality — FT8 / FT4 / FT2** displays
audio and buffer status plus optional CAT ALC values.

PSK Reporter and its calling tools remain included. **Call station enables
transmission in the next configured TX period. FT2 remains experimental.**
GitHub Actions builds the release tag and runs integration, codec, native
kernel, audio, SMP, logbook/UDP, and standalone-package checks before
publication. These checks do not establish improved RF sensitivity or range.
Source archives are available on the release page; both packages include
the GPLv3 **COPYING** file.
