# WSJT-X OE3SRO Custom — Windows-Release 3.0.2-oe3sro.6

**Windows x64 · build by OE3SRO · Basis WSJT-X 3.0.2-devel**

## Neu seit .5

- **Experimentelle Websteuerung im LAN:** Unter **View → Web control
  (experimental)…** einschalten, eigenen Zugangsschlüssel setzen und die
  angezeigte Adresse im Browser öffnen. Decodelisten, Frequenz/Modus,
  RX/TX-Steuerung, QSO-Felder, Sendetexte, Logbestätigung und Wasserfall
  bedienen dieselbe laufende Station. Einrichtung und Spezialdialoge bleiben
  am Desktop. Nach einem Neustart ist der Webserver ausgeschaltet.
- **Deutsch und Englisch:** automatische Sprachwahl und manuelle Umschaltung;
  Desktopfarben, Textformatierung und PSK-Reporter-Hervorhebungen werden
  übernommen. Die Offline-Anleitung enthält Originalscreenshots beider Sprachen.
- **Anmeldung repariert:** alle Webressourcen einschließlich `i18n.js` werden
  eingebettet und beim Build geprüft. Vierstellige Schlüssel einschließlich
  führender Null funktionieren. Querystrings und Skriptladefehler werden
  korrekt behandelt; Zugangsschlüssel werden nicht gespeichert.
- **WASAPI-Loopback:** Behandlung von Diskontinuitätsmarkern und Wiederanlauf
  nach Lesepausen verbessert. `start-wasapi.bat` startet einen eigenen reinen
  WebSDR-Empfänger, auch neben einer laufenden Senderinstanz.
- **HackRF FT8 auf 17 m:** zusätzlicher Starter
  `start-hackrf-ft8-17m.bat` mit eigenem Profil. USB-/TCI-Start und RX-Erholung
  sind robuster; Bereitschaft wird erst nach echten Empfangssamples gemeldet.
  Die HackRF-Runtime muss weiterhin separat bereitgestellt werden.
- **Build und Release:** lokale vollständige Neubauten mit MinGW Makefiles;
  Produktions-Webressourcen werden geprüft. Release Notes werden vor dem
  Release-Build validiert. Tag-Push und manueller Release-Start werden
  unterstützt; ZIPs und SHA256-Dateien werden vor Veröffentlichung geprüft.

## Download und Bedienung

**windows-x64.zip** vollständig entpacken und **Start-WSJT-X.bat** starten.
Windows 10 oder neuer ist die Zielplattform. EXEs, Decoder, Qt/OpenSSL-DLLs,
Hamlib-Tools, Stationsdaten und deutsche/englische Anleitung sind enthalten.
**documentation.zip** enthält die Anleitung separat. Beide ZIPs haben
SHA256-Dateien; `build-info.json` dokumentiert Version, Quellcommit und EXE-Hash.
Bestehende Profile bleiben erhalten; persönliche Einstellungen und Logs
werden nicht mitgeliefert. Die Anwendungsbasis bleibt 3.0.2-devel.

Die Websteuerung ist für ein vertrauenswürdiges LAN/VPN bestimmt; HTTP ist
unverschlüsselt. **Call station aktiviert TX. Ein Browserabbruch beendet TX
nicht.** FT2 und REIST16 bleiben experimentell. REIST16-QSO/2 bleibt gegenüber
.5 unverändert; dieses Release beansprucht keine neue Empfindlichkeitsgrenze
und keinen zusätzlichen abgeschlossenen Hardware-QSO-Nachweis.

Der Release-Workflow baut den Tag **oe3sro-v3.0.2-6** und veröffentlicht erst
nach Integrations-, Webserver-, Codec-/TX-Audio-, REIST16-, simulierten
Pluto-/HackRF- und Paketlaufzeitprüfungen. Diese CI-Prüfungen öffnen keine
Funkhardware und senden keine HF. Browserprüfungen wurden zusätzlich lokal
durchgeführt; sie sind kein Bestandteil dieses Release-Jobs.

## English

This release adds experimental LAN browser control of the running desktop
station, with German/English language selection, desktop decode colours,
PSK Reporter highlights and the live waterfall. Enable it under **View →
Web control (experimental)…**, set an access key and open the displayed URL.
Setup and special dialogs remain on the desktop. The server is off after
each restart. All web resources are now embedded and audited during builds;
login supports four-digit keys, including a leading zero.

WASAPI loopback now recovers from capture interruptions and reading pauses.
`start-wasapi.bat` launches a separate receive-only WebSDR instance.
`start-hackrf-ft8-17m.bat` provides a separate HackRF FT8 profile on 17 m,
with improved USB/TCI startup and RX recovery. HackRF runtime DLLs must still
be supplied separately. Updated bilingual offline guides include screenshots.

Extract **windows-x64.zip** fully and run **Start-WSJT-X.bat** on Windows 10
or later. Both the portable and documentation ZIPs have SHA256 checksums.
Existing profiles are preserved; personal settings and logs are excluded.
The application base version remains 3.0.2-devel, with **build by OE3SRO**.

Use browser control on a trusted LAN/VPN; HTTP is unencrypted. **Call station
enables TX. Disconnecting the browser does not stop TX.** FT2 and REIST16
remain experimental. REIST16-QSO/2 is unchanged from .5; this release makes
no new sensitivity or completed hardware-contact claim.

Release builds validate notes before compiling and publish only after CI
integration, web-server, codec/audio, REIST16, simulated bridge and portable
runtime checks pass, without RF hardware. Browser checks were performed
locally and are not part of the release job. Failed draft uploads can be
retried; published releases require a new tag for further changes.
